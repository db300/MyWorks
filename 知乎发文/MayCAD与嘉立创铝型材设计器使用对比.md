# MayCAD 用了几年，我为什么把铝型材设计搬到了嘉立创？

> 配图说明：文中 4 处“【配图】”为占位，图片制作完成后按文末清单中的文件名替换即可。

如果你也玩铝型材 DIY，大概率绕不开两个名字：MayCAD 和嘉立创铝型材 DIY 设计器。前者是很多人的入门工具，我也是；后者是我最近用得越来越多的在线工具。

先说结论：MayCAD 依然好用，只是我的需求从“把图画出”变成了“把东西买对、买齐、尽快做出来”。这两个工具看起来都在画铝型材，实际上解决的是两个阶段的问题。

## 一、MayCAD 是“画笔”，嘉立创更像“工具箱”

MayCAD 是典型的桌面软件：安装在本地，型材库、连接件、图纸文件都在自己电脑上。它的好处是自由、离线、不依赖平台，你想怎么搭就怎么搭，画完导出 BOM 或图纸，再拿着清单去找熟悉的供应商。

嘉立创铝型材 DIY 设计器则是浏览器里的在线工具：打开网页就能画，设计稿存在云端，型材和配件直接调用嘉立创 FA 的物料库，画完能生成 BOM、实时计价，甚至一键下单。它不追求“什么都能画”，而是把“标准铝型材框架从设计到采购”这条路缩短。

所以这两者不是简单的谁替代谁。MayCAD 强在“画图的自由度”，嘉立创强在“从图到货的确定性”。

## 二、我迁移的第一个原因：安装和文件，被“本地”困住了

我以前用 MayCAD，最麻烦的不是画图，而是“换电脑”。

它需要在本机安装，设计文件也保存在本地。家里一台电脑、公司一台电脑、偶尔用笔记本，想接着改图，就得先把文件拷过去；用网盘同步也不是不行，但版本一多，很容易出现“最终版”“最终版2”“最终版真的不改了”这种文件。更别说换新电脑，软件要重装，之前的库和习惯设置也要重新弄一遍。

嘉立创这边就简单很多：浏览器登录账号，设计稿在云端，换台电脑打开就能接着改。临时想给朋友看方案，也不用发文件，直接分享设计稿链接就行。

当然，云端不是没有代价：没网的时候干不了活，账号和平台服务也是前提。我的做法是，重要方案定期导出 BOM 或图纸留档，不完全把平台当唯一备份。

另外，MayCAD 是 Windows 软件，原生不支持 macOS，Mac 用户还得装虚拟机或者找替代方案；国内下载渠道也比较杂，官网时好时坏，很多人第一次接触用的都是汉化包或网盘版。这些对老用户不算事，但对刚入门的人，确实是额外的门槛。

## 三、第二个原因：改尺寸这件小事，嘉立创更“直给”

铝型材设计的大部分时间，其实不是在“建模”，而是在改尺寸：架子深一点、层高一点、横撑挪个位置。

MayCAD 的方式更接近传统 CAD：选中型材，在三个方向移动、拉伸，冲突的地方会标红，再慢慢调。它很自由，但前提是你得理解型材的朝向、连接方式和空间关系。对熟手来说这很顺手；对新手来说，改一个尺寸可能牵动好几根料，连接件还要自己一个个放。

嘉立创的设计器更像“搭积木”：选中框架，直接改数值，尺寸变化更直观；连接件会根据型材关系智能匹配，加工信息也能跟着更新。对于 2020、3030、4040 这类标准框架，这种“少想一步”的交互确实快很多。

但这里要说句公道话：自由和约束是一体两面。嘉立创的引导式交互适合标准结构，遇到特别非标、特别复杂的架子，MayCAD 那种“想怎么画就怎么画”的自由度仍然有价值。也有老用户觉得嘉立创设计器早期的完成度不如 MayCAD，这很正常——它还在快速迭代，而 MayCAD 已经是个很成熟的工具了。

## 四、第三个原因：从“画完”到“买齐”，中间少了一段路

这是我觉得两者最大的区别，不是界面，而是工作流。

用 MayCAD 的典型流程是：画图 → 导出 BOM → 去淘宝或本地商家询价 → 自己数连接件 → 和商家确认切割、攻丝、公差 → 分几家下单 → 等货 → 发现少买了几个角码，再补单。

用嘉立创的流程是：画图 → 一键生成 BOM → 实时看价 → 一键下单。型材、连接件、加工信息都在同一个体系里，少了很多“来回确认”的环节。尤其是对第一次做铝型材的人，最怕的不是画不出来，而是“买错规格、漏买配件、攻丝没沟通清楚”。设计器把这些问题提前暴露在图纸里，这是它最实在的价值。

不过，这个优势也有边界：嘉立创的物料库以自家在售的型材和配件为主，如果你习惯用某家淘宝店的型材，或者需要大量非标件，MayCAD 这种“只负责画图、不绑定供应商”的方式更灵活。另外，方便不等于最便宜，下单前还是建议比一下价。

## 五、一张表看懂差别

| 维度 | MayCAD | 嘉立创铝型材设计器 |
|---|---|---|
| 安装 | 本地 Windows 客户端 | 浏览器在线使用 |
| 文件 | 本地保存，手动同步 | 云端存储，账号同步 |
| 离线 | 支持 | 依赖网络 |
| 上手 | 功能集中，教程较分散 | 引导式，零基础友好 |
| 改尺寸 | 三维移动/拉伸，自由但需理解结构 | 直接改数值，连接件智能匹配 |
| 型材库 | 欧标库丰富，不绑定供应商 | 嘉立创在售欧标/国标系列 |
| BOM | 可导出，配件需自己核对 | 一键生成，和下单物料对应 |
| 报价/下单 | 导出后自行询价 | 实时计价，一键下单 |
| 协作 | 传文件 | 分享设计稿链接 |
| 适合 | 离线、复杂/非标、自由选供应商 | 多设备、标准框架、快速报价下单 |

## 六、我现在的用法：不站队，按阶段选

如果是标准架子——置物架、工作台、设备框架、简单的柜体——我现在会直接在嘉立创里画。改尺寸快，画完就能看到价格，确认没问题直接下单，省下来的时间比省下的那点材料费更值钱。

如果是复杂结构、非标件比较多，或者客户指定了供应商，我还是会打开 MayCAD。先把结构推敲清楚，导出 BOM 和图纸，再决定去哪里采购。有时候也会先用 MayCAD 做方案，再在嘉立创里按标准件重新搭一遍核价，相当于“自由设计 + 标准件落地”。

## 七、几个避坑提醒

1. 不管用哪个工具，下单前都建议核对一遍连接件数量、切割角度、攻丝要求和公差。工具能减少错误，但不能替你做最终检查。
2. 云端方案再方便，也建议定期导出 BOM 或图纸备份，别把唯一版本留在平台里。
3. 嘉立创方便，但不代表任何项目都最划算；MayCAD 自由，但本地文件和安装问题也要提前规划。
4. 铝型材 DIY，结构安全永远排在工具效率前面。承重、连接方式、地脚固定，这些不是软件能替你决定的。

## 最后

MayCAD 像一把用了很久的旧螺丝刀，顺手、自由、不挑场合；嘉立创更像一个把螺丝刀、五金店和加工厂放在一起的工具箱，省心、快，但你要接受它的体系。

所以我的建议不是“赶紧换”，而是先问自己：你现在缺的是画图的自由，还是从图到货的确定性？

如果你只是偶尔做一个标准架子，嘉立创足够；如果你喜欢折腾复杂结构、想自由选料，MayCAD 仍然值得留在电脑里。两个都留着，按项目切换，可能才是铝型材 DIY 最舒服的状态。
