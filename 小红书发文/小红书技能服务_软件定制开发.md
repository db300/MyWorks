## 二、技能服务内容（完整版，可直接粘贴）

我是做企业级软件开发的，长期负责系统的开发、部署和上线后的维护。接个人和小团队的需求：把口头想法整理成明确的功能清单，做成能运行、能给源码的系统或工具。

**一、我能做什么**

1）网站与后台系统
· 内部管理系统：客户、订单、库存、审批、报表
· 数据看板：把 Excel、数据库里的数据做成可视化页面
· 预约、报名、会员、问卷这类轻应用
· 已有网站/系统的功能增补、接口对接、老项目维护
技术栈：.NET / C#、PHP、MySQL、前端 HTML/CSS/JS；可以按你现有的服务器环境适配。

2）自动化与效率工具
· Word / Excel / PDF 批量生成、拆分、合并、按模板套打
· 公开网页的数据采集、定时任务、消息提醒
· 文件批量重命名、归档、格式转换
· 浏览器重复操作自动化
· Windows 桌面小工具、命令行工具
适合“每天手工做很多遍”的场景，做完能省下重复劳动。

3）AI 能力落地
· 文档批量解析、摘要、字段提取
· 基于现有资料的知识库问答
· 把多个步骤串成 AI 工作流 / Agent
· 图片、视频的批量处理流水线
按你的预算和可用模型选型，不承诺“全自动、无人值守”。

4）部署与运维
· Windows Server / IIS、Linux 基础环境部署
· 阿里云 ECS、域名、HTTPS、数据库配置
· 数据备份、日志、监控、故障排查
· 现有项目迁移、环境重装、性能问题排查

**二、交付内容**
· 开工前确认的需求清单（做什么、不做什么，写清楚）
· 可运行的完整源码
· 部署/安装文档，含一次远程部署
· 验收后 7 天内修复功能缺陷（不含新增需求）
· 可选：按月维护，另行报价

**三、服务流程**
1. 你说明场景：给谁用、解决什么问题、现在怎么做的
2. 我评估可行性、工期和费用，给出简短方案
3. 确认范围与首款后开工
4. 分阶段演示，你确认后再往下做
5. 验收，交付源码和文档
6. 进入售后期

**四、费用说明**
· 小脚本、小工具：¥500 起
· 网站、后台系统：¥5,000 起，按功能模块评估
· 维护：按次或按月
· 服务器、域名、短信、第三方接口、商业组件等费用另计
· 需求变更单独评估
具体价格以确认的需求清单为准。

**五、不接的需求**
· 外挂、破解、非公开或隐私数据采集、刷量刷单
· 赌博、色情、诈骗等违法业务
· 代写论文/作业、伪造材料
· 需要医疗、金融等特定行业资质的系统
· 只有一句“做个淘宝”“做个微信”但没有具体范围的需求（可以先帮你梳理，梳理按咨询计）

**六、沟通与下单**
· 工作日 24 小时内回复，周末可能延迟
· 我每周可投入的时间有限，排期以确认时为准
· 全程在小红书内沟通和下单，不走站外交易
· 咨询前准备好：使用场景、使用角色、核心功能、参考产品、预算范围，报价会准很多
